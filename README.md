# Bound Exodus Build
Bound Exodus: A Dynamic Turn Based Combat Game

This is a very short pre-alpha displaying the simple mechanics of Bound Exodus. The game showcases the unique core system of the project, with its turn based system designed to adapt dunamically in an auto-play fashion. 


## Installation
To install the game, simply download the code ZIP file and extract the contents. Then simply open the folder and run the .exe, to exit the program one must alt-f4 or close the program from the taskbar.
In later states and releases more and more basic QoL features will be implemented.

## How To Play / What To Do
As of right now there is there are no tutorials to guide you, and thus will be provided here.

### Hub Scene
Upon loading the game, you will be presented with the hub screen, this is the first half of the interactable sections. For now simply click on the pathway that leads towards the Citadel. Once inside the citadel area find the hexer's doorway click area and enter the hexers quarters. From there you will be able to summon 2 units using the realm pull system. Once 2 units have been pulled head back to the main hub screen to find the gate area. Look for the gate pathway, this will be where expeditions will begin. select your 2 new units from the unit selection panel, then select the forest on the map and then begin expedition. 

### Expedition and Battle
Once loaded into the expedition, you will see buttons on the cardinal points of the screen. These will traverse you through the tiles in that direction. As of right now the map is laid out in a 5x4 (x,y) fashion. As of right now there are no traversal animations, so you will be able to spam through the buttons until reaching an enemy populated tile.

Once within battle there are 2 phases: planning, and execution. The planning phase allows you to choose moves that will be performed, in order of speed based on all combatants on the battlefield. An ability has a main execution action that will be performed upon that units initiating turn, however it also has the possibility of having a pre-action, reaction, and combo action. Each of these actions can have conditions that must be met in order to execute. Abilities execute in this manner:
